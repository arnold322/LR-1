# ЛР 1

Android-приложение. На экране имя и фамилия, группа и картинка.

- Мусатов Тимофей — серым, слева снизу
- Т-433901-ИСТ — красным, справа сверху
- бабочка по центру
- кнопка «Скрыть надписи» прячет и показывает имя и группу
- кнопка с иконкой глаза прячет и показывает картинку

## Запуск

Нужны Android Studio и JDK 17.

1. Открыть папку проекта в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или на телефоне с включённой отладкой по USB.
